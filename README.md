# AOR2 Project - KVM Hypervisor

This project was developed as part of the Computer Architecture And Organization 2 course at the School of Electrical Engineering, University of Belgrade.

It is written in C and uses Linux KVM to run guest virtual machines. The project includes host and guest code, file operations, communication through I/O ports and interrupt handling.

The `host` folder contains the hypervisor code, while the `guest` folder contains the code executed inside the virtual machines.

**Note:** The project requires a Linux environment with KVM support to build and run.
